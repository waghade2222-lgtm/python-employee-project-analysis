# Python Employee & Project Data Analysis

## Project Overview
This project focuses on analyzing employee, seniority, and project-related data using Python. It demonstrates practical data manipulation, data cleaning, and analysis techniques to improve data quality and support business decision-making.

## Objectives
- Explore employee, seniority, and project datasets.
- Identify and handle missing project cost values.
- Apply conditional logic to update employee bonuses.
- Update employee designations based on defined criteria.
- Prepare data for further analysis and reporting.

## Tools & Technologies
- **Python** — data manipulation and analysis
- **Pandas** — data cleaning and DataFrame operations
- **NumPy** — numerical operations, where applicable
- **Jupyter Notebook** — interactive coding and documentation
- **CSV** — dataset format

## Project Workflow
1. Loaded the datasets into Python DataFrames.
2. Explored the available data and columns.
3. Identified missing values in project-related data.
4. Applied data-cleaning and conditional logic.
5. Updated bonus and designation fields according to the project requirements.
6. Reviewed the resulting datasets.

## Skills Demonstrated
- Data cleaning and preprocessing
- Missing-value handling
- DataFrame manipulation
- Conditional statements and logical operations
- Working with multiple datasets
- Exploratory data analysis fundamentals
